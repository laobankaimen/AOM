# AOM 界面与交互设计说明

更新日期：2026-11-03。本文定义当前桌面Web界面的设计规则与验收要求，作为后续开发和修改的统一依据。具体操作见[使用说明](使用说明.md)与[网络拓扑使用说明](网络拓扑使用说明.md)，数据规则见[接口说明](接口说明.md)。本轮不扩展手机适配。

## 1. 操作原则

常用操作应在当前对象附近直接可见：查看、选择、上架/下架、机位、状态、网络成员、显示层、连接确认等尽量就地完成。只有完整资产属性、高级网络配置和复杂布局资料进入详细编辑页。

操作先说明对象和范围，再提供动作。按钮名称使用“添加设备”“移出网络”“删除链路”等明确动词，避免把不同对象统称为“配置”。同一功能保留一个主要入口，辅助入口用于上下文快捷操作，不堆叠同等重要按钮。

查看或开关辅助面板不得修改业务数据、重置用户展开方式或重排正在查看的图形。修改应即时预览或在保存成功后明确更新；失败要保留输入并说明重试方式。真实数据与示意图不能混淆。

## 2. 页面结构与视觉层级

沿用深色工作区导航、浅色内容区、蓝色主操作、克制的边框与留白。重点通过位置、文字、间距和状态共同表达，颜色不单独承担含义。

- 顶部显示项目与当前位置，侧栏切换空间、拓扑、台账、型号和模板等工作区。
- 总览显示概况与继续操作入口；少量机房卡片及容器按内容限宽，单卡最大440px，不把状态数分散到宽屏两端。
- 图形页面优先保留画布空间。对象摘要放在详情侧栏，完整资料按需编辑，统计与帮助可折叠。
- 同一工具栏按钮统一高度、字号、边框和图标大小。按任务分组，主操作用蓝色实底，普通动作使用次级按钮，删除使用明确危险色并确认。
- 搜索与范围说明独立于业务动作，不把搜索框、新增、网络统计、导出和高级工具挤在一行。
- 长名称在图中可截断，完整名称须能通过提示或详情查看。字段标签、输入内容和错误文字不能越界或互相覆盖。
- 底部工具条使用独立空间，不遮挡节点、连线、缩放命中区或详情动作。

常用桌面窗口以1280×800、1440×900和1920×1080检查；内容按可用宽度自然换行。辅助面板变窄不应触发业务图重新排列。

## 3. 导航、范围与状态保留

空间路径为“项目 → 空间总览 → 机房 → 微模块 → 机柜 → 设备”；拓扑路径为“项目 / 网络拓扑 / 机房”，当前选中网络另列包含路径。选择网络不进入独立页面；两个工作区分别保留上下文。

页面链接采用可识别的导航语义，支持返回、刷新及在新标签页打开。项目、机房、网络、搜索、分页和显示方式等可恢复状态写入地址；切换项目后清除不属于新项目的对象和筛选。

项目统计、设备列表与导出必须一致。点项目设备总数应进入该项目全部机房的台账，默认导出当前筛选范围，并显示条数；全项目导出另设明确入口。型号和角色等全局资源必须标明作用范围。

选中对象后先显示摘要并高亮；“收起详情”保留选择，“取消选择”清除选择。恢复详情入口始终可见。显示偏好按工作区保存，不因其他页面的折叠设置隐藏关键区域。

修改密码页独立占据页面，业务界面从DOM中移出，立即回到顶部并聚焦当前密码。返回工作空间恢复原页面、编辑上下文及滚动位置，不把密码表单追加到业务页下方。

## 4. 查看、快捷操作与详细编辑

| 场景 | 直接操作 | 详细编辑 |
| --- | --- | --- |
| 设备 | 定位、上架/下架、选择机位、切换状态、移出指定网络 | 名称、型号、IP、SN和其他资产资料 |
| 机房 | 选择入口位置、拖动入口、选择/进入模块、缩放和平移 | 完整机房资料与布局参数 |
| 网络 | 创建、基本修改、添加成员、移出成员、删除 | 颜色、备注和完整成员清单 |
| 设备排列层 | 各网络独立显示/隐藏层名称；设备分配独立设置并立即保存 | 专用窗口自定义层名、数量、排序与批量分配 |
| 链路 | 确认/改回待确认、删除 | 简洁窗口维护端点、端口及可选资料 |
| 型号库 | 搜索、CSV预览导入、导出、角色管理 | 型号参数和新角色定义 |

“移至待上架区”在设备详情直接显示，不放入更多操作。上架表单只列可连续容纳设备的空闲U位；0U设备不出现无效上架动作。维护状态变更应保留真实机位语义。

机房入口用简洁的方向选择与图上示意表达，选择自动保存、画面立即反映修改；可拖动微调。保存失败保留预览，清楚标记尚未保存并提供重试，不要求重复打开复杂编辑页。

## 5. 网络拓扑工作区

### 同一机房一张图

主要对象统一叫“网络”，不并列使用“新增子网”和“网络分区”两种创建入口。每个网络是一个矩形，内部网络真实嵌在父框中。父框没有直属设备时仍保留容器，空网络也有添加设备入口。

顶部明确选择机房，图中保留本机房网络、相关跨机房网络、必要的上级框以及待指定机房的旧空网络。点击网络标题打开详情，保持当前滚动位置和缩放，不再提供重复的圆形选择按钮。网络选择只高亮和确定操作对象，不过滤掉父级、兄弟网络或真实跨网连接。只有明确点击“定位”才在画布内滚动到网络标题，不滚动整个页面或强制对齐整个父框。顶部路径显示工作区与机房，当前操作网络和包含路径独立说明。

网络列表只作查找定位。主要工具分为网络、设备与连接、查看三组，统一34px高度；新增、修改、添加成员及删除无需先展开网络列表。统计、批量连线和推演保留在辅助面板。

### 统一创建与放置预览

顶部“新建网络”默认放在机房最外层；网络标题＋号和详情“在此新建网络”使用同一表单，预选所在父框。默认只显示名称、所属机房和放置位置；用途、VLAN、网段、网关在可选资料内展开。项目内名称唯一，重复即时反馈并可定位已有网络。

原图用虚线预览放置位置，创建确认前不写数据。保存后留在同一张图，新网络立即可添加设备。多机房全图中创建时必须明确选择所属机房或跨机房，不能默默猜测。旧记录无法推定机房时保留并提示待指定。

### 改名、调整上级与移动位置

详情顶部直接改名、选择机房或放置位置，预览后应用；完整成员、颜色和备注使用高级资料。调整上级禁止自身、后代和跨项目，最多8层。包含关系是组织与显示，不继承VLAN、成员、IP或真实连接。

拖动网络标题只调整图上位置，父框及全部内部网络和设备一起移动，预览与保存一致。上级关系通过明确操作修改，普通拖动不能同时改变包含关系。同级框碰撞提前提示并取消，父子包含不被当作碰撞。调整上级后网络在新容器内重新排列，资产和内部设备局部位置保留。

### 设备与连接

未分配设备默认可见，无网络时仍能查看设备。添加支持批量选择、搜索、角色/模块筛选和图上拖入；移出在设备详情每个所属网络旁直接显示。移出清理指定归属及失效标签，保留资产、物理机位、其他归属与真实连接，最近一次成员变更可撤销。

多网络设备保留一张固定卡片，不随当前选择跳框；选中时突出所有相关网络，详情可定位每个归属。台账IP独立于网络接口地址。

可Ctrl/⌘选择两台设备后直接连接，也保留两端独立搜索的链路表单。默认待确认，已确认物理连接要求两端端口，网络、介质、速率和备注按需展开。详情直接确认、编辑或删除，删除确认显示真实两端对象。关系标签必须锚定其对应线段；密集时显示线上紧凑标记，禁止挪到无关空白位置。拖动、缩放与展开后仍保持标签与线的对应。

### 分层显示与排列设置独立

网络包含关系、型号角色和设备排列层分别维护。选中网络后，详情直接提供“显示层名称与分隔线”开关，以及“设置排列层”入口。开关属于当前浏览器的查看偏好，点击即时生效，按网络记住选择；不提交业务数据，不需要保存按钮，不产生修订或业务审计。旧记录的layersVisible用作没有本地选择时的初始值；新网络默认隐藏，旧数据已定义自选层时默认显示。

显示时，每个层通过不同节奏和颜色的横向虚线、淡底纹与层名称分隔，不只依赖颜色。分隔线限制在所属网络的直属设备区域，避开内部网络。隐藏只移除这些视觉标识，不重排设备、不改变框尺寸。全局隐藏辅助说明和专注画布不能覆盖网络自身的显示选择。

名称、数量、顺序和设备分配在独立“排列层设置”窗口维护，修改后显式保存；窗口不再包含显示开关。支持增删、上移/下移、拖动排序及批量分配。改层名保留手动坐标，有效层或层序变化时只重置受影响设备。

网络内部空白、层名称、分隔线及底纹仅作画布背景，不打开设置窗口，不阻挡平移或设备拖放。只有明确的设置入口打开排列层设置，点击网络标题仍原地打开详情。

### 稳定性与可读性

开关详情或网络面板只调整可视区，全部节点排列和当前缩放保持不变；选择网络不重置设备合并/展开。浏览器窗口实际改变尺寸时才按新窗口排列。选中对象可滚入可见区，不自动缩小文字。

搜索保留命中对象的一跳邻居，可主动只看匹配。合并要求型号、完整归属、排列层和连接特征一致，核心/汇聚设备独立。默认100%实际比例，显式总览适配全图。超过300张卡片时提示合并、筛选机房或搜索，不静默丢弃对象。

## 6. 拖动、缩放与即时反馈

拖动开始后要明确当前对象、目标和操作含义。图位置、网络归属、物理机位分别处理；Shift加入另一网络时保留原归属，普通跨网拖动表示移动。Esc取消，拖动期间锁定可能破坏坐标的缩放或重排。

无效U位、网络重叠、父级环、跨项目目标应在松手前提示，不能先提交再让用户猜测失败原因。拖动失败保留原状态，不产生部分修改。

机房布局支持鼠标滚轮以所在点缩放；拓扑普通滚轮平移，Ctrl/⌘+滚轮按鼠标位置缩放，Shift+滚轮横移。图上提供明确的＋/－、百分比、总览/适应按钮，缩放不修改业务位置。

模板缩略图应表达真实保存的单双排、柜数、列间设施与柜名。缩减柜数或改成单排时同步修正越界设施，影响应能预览。创建与初始化统一使用“目标 → 清单 → 预览 → 确认”，不把不同导入能力藏在相似入口中。

## 7. 保存、错误与删除

未保存保护覆盖编辑页、快捷面板、弹窗、主导航、项目/范围切换及浏览器离开。仅有实际修改时询问放弃或继续编辑；保存期间禁止重复提交与退出，画布动作同时呈现禁用状态，不能接受点击后静默忽略。网络详情的动作始终绑定正在展示的具体对象，删除确认须显示该对象名称。密码不缓存为可恢复业务草稿。

保存使用打开草稿时的版本。冲突不把旧整对象换成新版本号强行重试，应保留输入、说明冲突并让用户退出载入最新资料后重编辑。失败提示在原表单就地显示并获得焦点；错误摘要与可修改字段相邻，不能只在页面顶部显示短暂消息。

删除使用明确对象名、影响范围与确认按钮，不要求无意义的额外步骤：

- 删除网络：保留设备与真实连接，清理该网络标签，直属子网提升到原上一级；其他归属保留。
- 删除链路：仅删除该连接记录，保留两端设备。
- 删除设备/机柜/模块：展示资产及引用数量，迁移、下架和连同内容删除分别说明；有影响的清理须明确确认。
- 型号和角色有引用时不能直接删除；同名导入冲突不能静默覆盖。

状态变更、引用清理与审计应原子提交，失败回滚。纯视觉坐标、配色及无变化保存不产生业务审计。提示条可关闭，需要恢复的操作提供明确撤销入口。

## 8. 键盘与可访问性

所有图标按钮须有可识别名称，原生控件优先。SVG设备、链路、网络和层标题支持焦点与键盘激活；输入标签、当前选择、禁用状态、错误和成功提示具有对应语义。焦点样式清楚，不只依赖鼠标悬停；提供跳过导航进入主内容的入口。

| 快捷键 | 作用 |
| --- | --- |
| Alt+N | 当前工作区新增 |
| Alt+I | 支持的工作区导入 |
| Alt+E | 编辑当前对象 |
| Alt+U | 选中设备移至待上架区 |
| Alt+L | 拓扑新增链路 |
| Alt+0 | 当前图总览/适应 |
| Ctrl/⌘+S | 保存当前表单 |
| Esc | 取消或关闭当前操作 |
| / | 聚焦当前工作区搜索 |
| ? | 查看快捷键说明 |

输入、组合输入和修改密码期间不触发业务操作键，不抢占普通文字输入。弹窗保持焦点，确认/关闭后能继续当前任务。技术标识如资产编号、IP、SN、网段和端口关闭拼写检查，使用合理的name与自动填写设置；密码保留管理器语义与粘贴能力。

## 9. 验收要求

| 验收场景 | 通过标准 |
| --- | --- |
| 多项目、多机房 | 统计、台账、筛选与默认导出范围一致 |
| 常用操作 | 下架、机位、状态、成员移出和链路确认不必先进入完整编辑页 |
| 网络嵌套 | 三级矩形逐级包含，空网络能操作，选择或返回不隐藏父级/兄弟网络 |
| 面板切换 | 比较全部节点坐标与缩放均不变化，画布及操作互不遮挡 |
| 可选分层 | 独立开关层名与分隔线，无写请求；设置使用独立窗口，开关前后坐标与框尺寸不变，空白点击不弹窗 |
| 链路 | 两端独立选择，可选字段按需展开；标签在线上，缩放/拖动后保持锚点；删除保留设备 |
| 草稿与慢请求 | 拒绝放弃时保留输入，保存中导航不能打断，冲突不覆盖其他会话修改 |
| 详情高度 | 常规桌面窗口下主要字段与常用动作直接可见；大量数据仍可滚动完整访问 |
| 机房入口与缩放 | 修改即时显示、失败可重试；滚轮缩放锚点稳定且不修改业务数据 |
| 键盘 | 常用按钮、SVG对象、表单及关闭恢复可操作，输入和改密不误触发业务动作 |
| 密码页 | 业务主界面不在DOM中；返回恢复原上下文 |
| 运行包 | 使用实际Linux可执行程序验收，内嵌页面与构建一致，文档及示例随包更新 |

较多网络/连接的详情仍可能需要滚动。Windows运行包在Linux交叉构建，不据此宣称已完成Windows现场运行验收。修改内嵌前端后必须重新生成可执行程序，单独刷新浏览器不能更新旧进程中的页面。
