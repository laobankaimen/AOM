# 网络拓扑与网络划分

## 1. 两种视图

左侧“空间总览”展示项目、机房、微模块、列、机柜与柜内设备；“网络拓扑”展示同一项目的设备连接与网络归属。两个工作区通过侧栏切换，共用顶部项目选择。页面内仅保留当前层级的导航和操作。

拓扑默认包含项目全部机房，可查看跨机房、跨点位上联。选择单一机房、网络分区或搜索设备后，只绘制两端都在当前范围的连接；界面明确显示有多少条连接因另一端在范围外而隐藏。

选中的设备或链路在图中高亮，右侧显示“已选中”和对象名称，可取消选择。点击拓扑设备查看机位、所属网络、台账IP和直连设备；点击“在机房中定位”进入对应机柜立面。未上架设备定位到设备台账。点击连线或线上的速率/关系标签查看两端端口、介质、速率、承载网络、来源和确认状态。标签支持鼠标点击及键盘Enter/空格键。

## 2. 网络划分

打开“网络与分层”，点击“新增网络分区”或“新增子网络”，在当前页面填写名称、选择用途即可创建。常用名称提供数据网络、管理网络、存储网络快捷填入；VLAN、网段、网关在选填区域展开。进入网络后点击“编辑当前网络”也使用快捷面板。

同一项目内的网络名称不能重复，子网络也遵循此规则。输入重名会立即提示，可直接打开已有网络。上级网络、颜色、备注和完整成员配置通过“高级编辑”进入独立页面，已经填写的名称和参数会保留。

### 批量划分与双上联

1. 创建数据网络、管理网络等分区，逐层进入需要配置的网络。
2. 点击“添加现有设备”，按角色、微模块或名称/型号筛选，选择“全选筛选结果”或勾选设备，一次加入。筛选变化会保留已选设备，提交前核对已选数量；已有的其他网络归属保留。
3. 点击“批量连线”，选择上联设备，再选择下联设备。两台上联交换机连接66台服务器时，会预览132条关系；已经存在的关系自动跳过。
4. 确认后创建待确认逻辑关系。需要记录真实线缆、双端口或速率时，再进入链路编辑页核实；快捷操作不会推断真实布线。

批量加入或批量连线各在一次事务中保存；任何无效设备或数据冲突都会取消整批操作，不保留部分结果。批量连线支持1–8台上联设备、最多2000条关系，不允许同一设备同时位于两端。

网络分区用于展示归属，不代表交换机配置已经下发，也不证明安全隔离已生效。不同分区可以填写相同VLAN编号；软件不会据编号推断不同机房的广播域相同。网段需填写网络地址，例如10.20.0.3/24会被拒绝。

多网络设备只绘制一次，默认位于第一个所属分区，卡片徽标显示其所属网络；选择某个网络时展示该分区的全部成员。设备详情显示全部网络及各自的VLAN、网段和网关。设备台账IP是单独资产字段，不视作所有接口或所有分区的地址；当前不提供接口IP池和防火墙策略管理。

## 3. 连接管理

“新增链路”选择同一项目的两个不同设备，并录入物理连接或逻辑关系。支持跨机柜、跨模块、跨机房连接。

| 字段 | 规则 |
| --- | --- |
| 两端设备 | 必须存在、属于当前项目，不能连接自身 |
| 两端端口 | 使用现场端口标识；每端最多80字符 |
| 介质 | 光纤、铜缆等台账描述，可留空 |
| 速率 | 单位Gbps，0表示未确认；不代表实时带宽 |
| 状态 | 待确认 / 已确认；不是链路在线状态 |
| 承载网络 | 可多选；两端必须都是所选分区成员 |
| 来源 | 手工或按型号推演，由系统记录 |

同一物理端口只允许属于一条物理链路；不区分端点A/B，忽略端口名首尾空格及字母大小写，待确认但已填写端口也会预占。两端均填端口后才可确认物理链路。多个网络共用一条物理线缆时，在该链路中多选承载网络，不重复建线。

同一对设备允许多条使用不同端口的物理线缆，表达双网卡或冗余连接；逻辑关系按设备对唯一，并在一条关系上多选网络。物理和逻辑关系可同时存在。端口容量、合法槽位与型号端口模板尚未强制建模，端口名称与速率须现场复核。

在图上点击链路或切换“链路清单”可编辑与删除。实线表示已确认物理连接，虚线表示待确认，点线表示已确认逻辑关系。图线不播放实时流量或模拟在线状态。

## 4. 按型号推演

先创建分区并选定成员，再筛选该网络，打开“拓扑更多操作 → 按型号推演”。

系统按核心→汇聚→接入/管理接入→服务器/存储层级，为缺少上层连接的成员寻找最近的已有上层角色；同层级候选优先同微模块。缺失层级时可连接最近的上层设备；缺少上层成员则不推断。基础设施角色不参与网络层级推演。

预览不写库。确认后生成“逻辑 / 待确认 / 推演”记录，不填造端口、介质、速率、IP、VLAN或冗余关系。不覆盖人工记录；设备对已存在连接时跳过，现有链路的网络归属需人工编辑。重复推演不会重复添加同一连接。该规则不保证真实网络冗余、路由或布线正确，需要逐条核对。

确认时检查数据revision；期间有其他变更则拒绝提交，必须重新预览。推演为空时不产生审计或空变更。

## 5. 保护与审计

网络与链路的实际新增、业务参数修改、删除、推演提交与前后变化对象在同一事务保存；纯配色和图形排列不产生审计。校验失败或旧revision冲突不会产生部分修改。

- 设备有链路或网络成员关系时，禁止直接删除；先调整连接和成员。
- 删除网络时保留实际链路，只移除链路上的该网络标签；网络下有子网络时先迁移子网络。
- 移除分区成员导致链路端点不再属于分区时，禁止保存。
- 移动机房/模块/设备到其他项目时，若使现有网络归属或连接跨项目，则拒绝；先整理网络关系。

## 6. 显示范围与导出

图默认按角色层级纵向、网络分区横向排列，支持滚动、缩放、搜索和设备自由拖动，图位置持久化。单击网络卡片逐层进入，面包屑返回上层，当前范围包含所选网络及其子网络。单图最多显示300张卡片；合并卡片可包含多台设备，展开后超过上限时提示缩小范围，不静默丢弃节点。链路清单保留当前筛选内全部连接，JSON导出包含当前项目全部设备、网络和链路，与图中搜索筛选无关。

导出JSON用于审查和共享，不是完整数据库备份，本期未提供拓扑JSON导入。模型、机柜和审计等完整迁移仍采用停机复制data目录。

## 7. 直接移动与详细编辑

- 拖动子网络卡片到其他网络或面包屑调整父级。禁止自身/后代父级、跨项目和超过8层。
- 在网络区域内拖动设备只保存图位置，Alt+方向键微调，Esc取消，可恢复自动排列。
- 跨区域或拖到网络卡片移动设备/设备组；按住Shift拖动表示加入目标网络且保留原网络。也可通过“设备网络设置”精确选择目标，加入/移出不删除设备。移动清理原分区失效链路标签，保留实际端口和线缆，不填造目标网络标签。
- “添加现有设备”直接加入成员；“拓扑更多操作 → 新建设备”进入资产编辑页，保存后再加入网络。“删除设备台账”位于设备详情编辑页且有引用保护。
- 网络、VLAN、网段、设备属性和链路端口等详细信息统一进入编辑页，确认/推演预览可使用对话框。
- 删除网络前必须迁移子网络，设备和实际连接保留，网络标签移除。父子组织关系不继承网段和成员，不表示地址划分或策略已生效。

拓扑导出位于“拓扑更多操作”；设备的精确移网、移出子网、恢复自动排列位于“设备网络设置”独立页面。点击对象先查看，编辑按钮进入独立编辑页。

## 分组总览与逐台查看

默认“自动合并同类”将同型号、完整网络归属和显示层相同的重复设备折叠为数量卡片，包括服务器和交换机。合并仅影响显示，每台设备的资产、机位、IP/SN及连接仍单独保存；其他网络归属不同的设备不会因为当前筛选而被错误合并。

点击卡片在原图展开该组，其余网络和设备仍显示。图上方出现“收起型号（数量）”和“全部收起”按钮；“全部展开”显示当前范围内每台设备。展开和收起不写入数据库，不产生审计。图形单次最多300张卡片，展开将超限时需先按网络、机房或关键字缩小范围。

合并后的连接按设备组汇总并显示真实连接数量。点击连接组查看其中的逐条连接，再点击一条进入详情；组内连接数量显示在卡片上。密集图默认隐藏不重要的连线标签，悬停或选中可查看，也可在“显示选项”启用全部连线标签。

### 拖动设备、设备组与连接

- 拖动设备或折叠组的卡片移动位置，松手保存。整组位置一次保存，展开时保留成员间的相对位置。纯图位置调整不增加审计。
- 拖到另一网络分区或上方网络卡片，目标区域高亮，提示将移入的网络及设备数量；松手后移动成员。按住Shift拖动时，提示“加入、保留原网络”。设备组操作整批提交，失败时不产生部分结果。
- 在原网络之外的画布空白处释放只调整图位置，不修改成员；移出画布且未落到网络入口时取消。Esc可取消任何尚未释放的拖动。
- 展开设备后，拖动右侧“＋”圆点到另一台设备，建立待确认逻辑连接。已有连接时打开其详情，不重复创建。端口、实际介质、速率及确认状态通过“编辑连接与确认状态”设置。也可聚焦圆点按Enter，再点击目标设备完成连线。
- 放大后可拖动画布空白区域平移；设备拖到边缘时自动滚动。

## 自动排列与收起面板

设备按实际存在的角色紧凑排列，没有核心、汇聚设备时不预留空行。同一角色设备自动换行，多个网络按画布宽度换行；空网络仍能从网络列表进入，但不在画布中占据整块分区。分组总览和逐台设备使用同样的紧凑规则。

手动拖动的位置继续保留。如果已有布局留出较多空白，点击“画布操作 → 自动排列”，使用ELK计算连接相关的排序，再按自定义分层整理同层设备和网络间距，保存当前范围的新位置。操作一次保存，不产生审计；不改变机位、成员归属和链路，也不调整范围外设备或其他网络的手动位置。

拓扑默认将空间留给画布。顶部“网络与分层”打开浮动面板，包含网络列表、创建入口和筛选；统计数据位于面板内折叠区。设备/连接详情也是浮动面板，展开时不压缩或缩小画布。右上角最大化按钮让画布占满窗口，Esc退出；现有筛选始终生效，顶部“清除筛选”可解除。全局“界面显示”仍可控制侧栏和辅助内容。

## 图形缩放和文件导出

拓扑100%是实际显示比例，不会为了塞入整张图自动缩小文字。“＋／－”独立缩放，Ctrl／⌘＋滚轮以鼠标所在点缩放；滚轮平移，Shift＋滚轮横向平移，拖动空白区域或中键拖动也可平移。底部“总览”才按宽高缩放全图，点击百分比恢复100%。操作不改变网络、分层和图坐标。旧图若排列狭长，可使用“画布操作 → 自动排列”重新整理。

图标题旁“导出图形”提供PNG、单页PDF和SVG。导出当前筛选范围下的完整画布，包括屏幕外设备，保留分组总览或逐台展示方式。文件标题标注网络路径、机房、搜索条件和导出时间。PDF采用高清图像以保留中文外观，大型网络建议SVG；需要完整项目拓扑时先清除筛选、点击顶部“项目拓扑”。

## 导航位置

项目选择、网络路径与编辑位置统一显示在顶部。点击“项目拓扑”返回完整项目网络；侧栏“网络拓扑”也回到同一入口并清除筛选。点击路径中的网络名称逐层返回，不再需要到内容区域寻找另一条返回路径。

进入编辑页后“返回查看”保留原网络位置。从拓扑定位到机房后，可用“返回原网络拓扑”回到原网络及所选设备。切换项目仍保留拓扑工作区；刷新、浏览器返回与前进可恢复地址中的项目和网络路径。

## 移动网络分区与打开详情

逐台拓扑与分组总览均可按住网络分区标题移动整组设备，连接随之更新。松手保存位置，Esc或在画布外释放取消；Alt+方向键微调。位置刷新后保留，两种图共用同一组坐标；“自动排列”恢复当前范围的分区和设备自动位置。移动图上的网络不会改变层级、成员、连线或机位，不记审计。上方网络卡片拖到其他网络或路径仍是调整上级归属。

详情“×”只收起，不清除选择。图标题旁始终有“显示详情”入口；点击设备或链路也会重新打开详情。“取消选择”单独清除所选对象。

## 自定义网络内部显示层

通过“网络与分层”进入网络，再点击“画布操作 → 分层设置”。默认层由设备型号角色映射：核心、汇聚、接入、计算/存储、其他。

1. 在设置页新增层、修改名称。拖动层条目或点击“上移”调整上下顺序，最多16层。
2. 在设备表为每台选择显示层，或搜索后全选，批量分配到目标层。保存后按层重排。
3. 返回图中，将设备或设备组拖到目标层区域；目标区域高亮并提示层名，松手分配。空层也保留落点。
4. 删除层后，原层设备恢复自动映射；没有默认角色对应层时进入末层。删除层不删除设备。

分层只是图形组织，不修改型号角色、网络成员、链路或VLAN。一个多网络设备可在不同网络中有不同显示层。更改分层会清除受影响设备的手动图坐标，使其实际显示在目标层；同层内拖动仍可微调位置。

## 删除网络与未分配设备

“编辑当前网络 → 高级编辑 → 删除此分区”会先显示确认说明。有子网络时先移动子网络。确认删除后移除网络实体与成员归属，并从真实连接上移除该网络标签；设备资产、物理机位、真实连接及其他网络成员关系保留。

“未分配设备”不是网络，默认不显示在图中。“画布操作 → 显示未分配设备（数量）”可打开待分配区域，拖入现有网络或通过批量添加重新分配；也可随时从设备台账查看。

设备卡片只展示名称、角色或数量，机位、IP、VLAN、端口等在点击后的详情查看。默认突出网络边界、层标题和连接线；选中设备突出直连关系，其余连线淡化。重复设备合并及展开规则不变。

## 布局与连线避让

画布网格铺满整个工作区，可平移缩放；图形内容不再限定背景大小。网络分区或设备的旧坐标重叠时，显示自动避让，不自动改写数据库。展开设备组、窗口大小变化后也会重新检查重叠。

拖动网络到其他网络上方会提示并取消；需要全局整理时使用“画布操作 → 自动排列”。采用ELK层次布局计算连接相关顺序，按现有显示层和网络分别排布，整个提交保存一次。重要业务对象、层归属、机位、成员与链路保持不变。

连线使用水平/垂直通道绕开设备矩形。默认不铺满连接标签，悬停、选中或“显示选项”按需查看；标签优先放在空闲线段，避免遮挡卡片。较大图仍建议合并同类或进入单个网络查看。
