# 网络拓扑使用说明

## 一张图管理机房网络

顶部选择机房后，同一机房的网络、设备及其连接始终在一张图中。内部网络画在父网络矩形内部；父网络无直属设备时仍保留容器，空网络也能直接添加设备。跨网络的真实设备连接跨越框边界绘制，不把包含关系画成实际链路。

点击网络标题，只高亮并打开该网络详情，不进入新的网络页面，不隐藏父级和兄弟网络。顶部路径表示工作区与机房；当前操作网络及其包含路径在画布上方单独显示。网络列表只用于查找定位，常用操作在顶部、网络标题和右侧详情直接可用。网络标题上的＋、设备和修改按钮打开左侧浮层，画布保持原来的位置与缩放；关闭浮层也不回到左边。

“项目全部机房”查看跨机房结构。新网络明确指定所属机房，也可以选择跨机房；旧数据按设备位置显示，无法判断归属的空网络保留为“待指定机房”，可以在详情指定。

## 新建网络

页面统一使用“新建网络”，不区分“新增子网”和“网络分区”两种入口。

1. 点击顶部“新建网络”，或网络标题上的＋号（在此网络内新建）。
2. 输入名称，确认所属机房，选择放置在“机房最外层”或某网络内部。
3. 查看原图中的虚线预览；VLAN、网段、网关及用途需要时展开可选资料填写。
4. 创建后留在原图，新网络直接出现，可添加设备或继续创建。

顶部创建默认放在最外层；从某网络标题创建，默认放在它内部。项目内名称唯一，重名即时提示并可定位已有网络。包含关系表示组织与显示，不自动划分IP子网、继承VLAN或下发设备配置。

## 改名与调整包含关系

选中网络，在右侧直接修改名称、所属机房或放置位置，先查看虚线预览，再点击“应用名称与放置位置”。内部网络、设备和真实连接保留，禁止把网络放进自己或后代，最多8层。高级资料维护颜色、备注及完整成员清单。

拖动网络标题仅调整图上位置：父框、全部内部网络及其设备一起移动，松手保存；不改变上级关系和物理机位。Alt+方向键微调，Esc取消。同级网络重叠时提示并拒绝保存。旧版本内部网络的全图坐标自动按嵌套方式显示，不修改原记录；再次移动后按父框内位置保存。

## 添加、移动、移出设备

未分配设备默认可见，没有网络时也能查看项目设备。网络标题的“设备”、空框的“添加设备”及右侧详情都能打开批量选择，支持搜索、角色/模块筛选和全选筛选结果。添加保留已有其他网络归属。

设备拖到其他网络表示移动，按住Shift表示加入目标并保留原网络；未分配设备拖入表示添加，设备组同样支持。提示说明目标与影响，Esc取消。需要精确选择目标时使用设备详情的网络设置。

“所属网络”每行的“移出”只解除指定归属，保留资产、机位、其他网络和真实连接；失效链路标签同步清理。没有网络归属后回到未分配区。最近一次归属变更提供撤销/重做，发生其他写入后失效，避免覆盖后续操作。

多网络设备只保留一张固定位置的卡片，选择其他网络不会让卡片跳到另一个框。选中设备会突出所有相关网络，详情可定位各个归属。台账IP是独立资产字段，不代表所有网络接口地址。

## 分层显示与排列设置

选中网络后，在详情直接操作：

- “显示层名称与分隔线”：点击即时切换，不需要保存。显示时各层用不同节奏的虚线、淡底纹和名称区分；隐藏不改变设备排列、网络框尺寸、层顺序或设备分配。选择按网络记在当前浏览器中，不修改其他人的业务配置。
- “设置排列层”：打开独立窗口，改名、新增、删除、上下移动或拖动排序，单台/批量分配设备；修改完成后点击“保存分层设置”。窗口中没有显示开关。

层标识不受顶部隐藏辅助说明或专注画布影响。新网络默认隐藏，旧记录保留原显示偏好。层是排列规则，与网络包含关系及型号角色独立。改层名保留手动位置；改变有效层或顺序时只重置受影响设备的位置。删除层不删除设备，详情可直接调整选中设备所属层；拖入空层前在画布操作中显示空排列层。

点击网络标题查看详情，保持当前视野。网络列表或详情中的“定位”只在画布内滚动到目标标题。点击网络空白、层名或分隔线不弹出设置，可在空白处拖动画布或拖入设备。

## 建立和核实连接

按Ctrl/⌘点击选择两台设备，点击“连接这两台设备”可建立待确认逻辑关系；已有关系则打开原连接。也可点击“新增链路”，分别查找选择A、B设备，选择物理连接或逻辑关系，默认待确认，网络/速率/介质/备注按需展开。

物理链路确认前必须填写两端端口，同一物理端口不得重复占用，待确认但已填端口也会预占。承载网络只列两端共有网络，在选中网络内创建且两端均为其成员时默认关联该网络，可主动取消。两端都在当前图的未标记网络链路也会显示。

关系标签始终放在对应连线上；密集区域容不下完整标签时保留线上紧凑标记，通过悬停、键盘或详情查看。拖动网络、缩放或展开设备时标签与线路同步更新。

点击线或标签可查看两端端口、介质、速率、网络和确认状态，直接编辑、确认、改回待确认或删除。待确认/已确认是资料核实状态，不表示设备在线或流量。删除显示具体两端并保留设备。

展开设备后，也可将右侧＋圆点拖向目标设备；聚焦圆点按Enter再点击目标同样可创建待确认逻辑关系。图形不下发配置。

## 合并、搜索与批量操作

合并同类仅合并型号、完整网络归属、显示层及直接连接特征相同的设备，核心/汇聚保留独立。组卡片显示真实数量，展开不创建或删除资产。连接组可逐条查看并表达混合状态。

搜索默认保留命中设备的一跳相邻对象和连接，可选择只看匹配结果。选择网络、开关面板不重置展开方式、节点位置或当前缩放。超过300张卡片时提示合并、筛选机房或搜索，不静默丢弃节点。

网络列表中的批量连线先选1–8个起点再选目标，预览新增/跳过数量后一次创建，最多2000对，生成待确认逻辑关系。型号推演先预览再确认，不编造端口、介质、速率或冗余保证。

## 缩放、排列与导出

默认100%实际比例，点击“总览”适应全图，点击百分比恢复100%。普通滚轮平移，Ctrl/⌘+滚轮以鼠标为锚点缩放，Shift+滚轮横移；空白或中键拖动平移。缩放不修改对象图坐标。 同一层内可将设备拖到网络框中的空白位置，松手保存后及刷新后位置保持一致，设备分层、网络归属和连接保留。单台设备或合并组向左、向上移动后，图形边界即使缩短也保留当前画布视野，不因滚动范围变化而跳动；需要重新适应内容时主动点击“总览”或“100%”。底部工具条独立占位，不覆盖设备与连线；最大化用整个窗口，Esc退出。

自动排列使用ELK确定连接相关顺序，保留层定义、设备分配及嵌套结构；层名显示开关不影响自动排列，只保存当前范围图位置，不改变资产、机位、成员和真实连接。一次最多1000台，较大范围先筛选。

图形导出支持SVG、PNG、单页PDF，覆盖当前完整图。拓扑更多操作中的JSON导出包含当前项目全部设备、网络与连接，与图中搜索范围无关。链路清单按当前筛选分页。

## 删除与保存保护

删除网络显示名称、直属设备与内部网络影响。只删除当前网络，直属内部网络提升到原上一级，设备、机位、真实连接及其他网络保留，清理被删除网络的标签。设备台账删除另有资产与引用确认。

退出未保存表单或切换对象前确认放弃；保存中锁定退出与重复提交。版本冲突保留输入，不能用刷新出的新版本号重试覆盖他人修改。错误在原窗口就地反馈，事务失败不产生部分修改。

快捷键：Alt+N新建网络，Alt+L新增链路，Alt+E编辑对象，Alt+0总览，Ctrl/⌘+S保存，Esc取消。输入框和密码页内停用业务动作键。
