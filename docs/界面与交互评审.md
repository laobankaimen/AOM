## 用户现场反馈补充（2026-11-02）

- 修改登录密码时工作区残留：已改为通过实际DOM容器隐藏完整工作区，密码页回到顶部并聚焦当前密码；返回恢复原页面、编辑上下文及滚动位置。
- 初始没有网络时找不到设备：默认展示全部设备，未分配区域直接可见；无网络时默认全部展开。
- 创建空网络后没有分配入口：当前网络框与未分配区域同时显示，顶部提供添加现有设备，可拖入或批量勾选添加；网络成员数与画布总数分开标明。

## 实施核对（2026-11-02）

已按优先级处理本文件与《UI交互审查-2026-11-02》中的桌面端问题。手机适配、手机表格和手机侧栏按用户要求跳过。下方原始证据位置用于追溯，源码行号可能已随修复移动；各项的“当前处理”说明为准。

这轮先修复数据范围、草稿丢失、保存锁定、并发覆盖、无效拖放，再处理拓扑与桌面操作。冲突处理采用保留旧版本号并阻止覆盖，提供关闭编辑载入最新数据入口；没有静默自动合并字段。未保存离开提供“放弃 / 继续编辑”的原生确认，保存仍使用原表单按钮。

网络归属撤销/重做只作用于最近一次成员移动，恢复成员、设备显示层、手动位置与链路网络标签；发生其他写入后撤销入口失效，避免覆盖后续修改。单设备删除增加显式勾选的引用清理；其他设备和网络保留。

视觉检查已查看桌面总览、拓扑和实际模板缩略图。专项与回归结果见文末验证记录。

**统一设计方向**

项目 → 机房 → 微模块 → 机柜 → 设备维持一条空间导航；网络拓扑独立维持自己的网络层级。默认把空间留给图形，选中对象只显示必要摘要；拖动处理结构和位置，详情页处理复杂属性。任何会修改业务关系的操作都要清楚说明影响并能恢复。

**UI-01 · P1 · 导出台账的范围与页面不一致**

建议：默认导出当前筛选结果，按钮旁明确范围与条数；全库导出另设明确入口。
