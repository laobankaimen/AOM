# 使用说明

## 1. 启动、登录与备份

解压对应系统运行包。本机运行 `start-local`，浏览器访问 `http://localhost:8080`；局域网运行 `start-lan`，访问 `https://服务器IP:8080`。目标电脑无需安装Go、Node或数据库。

首次从后台控制台复制初始化令牌，创建管理员账号和密码。账号为3–64位字母、数字、点、横线或下划线；密码12–128字节。没有默认密码。当前为单管理员，右上角用户菜单可修改密码、退出或查看系统信息。

数据保存到 `data/app.vault`，密码用于解密，忘记后无法恢复。会话最长8小时、业务空闲30分钟过期；密码修改使所有会话失效。登录频率超限时稍后重试。

局域网脚本自动生成自签名证书 `data/server.crt` 和私钥。客户端核对证书后安装信任；主机IP变化或证书过期时更新证书。也可使用自己的证书：

```bash
./aom --addr 0.0.0.0:8080 --tls-cert /path/server.crt --tls-key /path/server.key
```

备份、换机或更新程序：停止后台，复制整个运行目录及实际data目录，使用对应系统程序启动，输入原密码。更新只替换程序和说明，保留data。旧备份使用备份时的密码。

若首次发现 `app.db`，按页面勾选只读导入；原库和旧备份不会自动删除，仍可能是明文。导出的CSV、JSON、图片和PDF也需自行保管。异常退出留下 `.aom.lock` 时，确认没有程序使用该目录，再移除锁启动。

## 2. 三步初始化

首页点击 **初始化机房**：

1. 选择已有项目/机房，或直接新建。
2. 下载填写模板，用Excel/WPS填写，另存CSV UTF-8后上传；网络参数和连接清单按需补充。
3. 预览模块、设备、网络、连接及待上架数量，核对后确认创建。预览不会写库。

总清单按“模块”分组，同机房同名模块复用，新模块按默认或指定布局模板创建。只必填型号、数量；已知机柜/U位先预留，其余自动寻找连续U位。型号高度未知或容量不足的设备保留待上架。

| 设备清单字段 | 用法 |
| --- | --- |
| 型号/model、数量/quantity | 必填；型号与型号库匹配，数量正整数 |
| 模块/module、布局模板/template | 模块可空，使用默认名称；新模块可指定模板名 |
| 名称/name、备注/note | 可选；批量自动加序号 |
| 资产编号/asset_tag | 固定编号须数量1，全库唯一 |
| 资产前缀/asset_prefix | 未填固定编号时生成唯一编号 |
| 机柜/rack、起始U/start_u | 起始U须同时指定机柜且数量1；只填机柜则柜内自动排位 |
| IP/ip、SN/sn | 数量大于1时留空；非空SN唯一 |
| 网络/networks | 网络名称，多个用分号分隔；同项目同名复用 |
| 设备角色/role、U高/u_height | 启用未知型号注册时填写角色；U高空或0表示待确认 |

“补充网络与连线”提供两个可选CSV：

- 网络参数：名称、上级网络、用途、VLAN、网段、网关。已有明确参数冲突时报错，不覆盖。
- 连接：源资产编号/source、目标资产编号/target；可填source_port、target_port、kind、speed、medium、networks、status。真实已确认物理线缆必须填写双端口。

一批最多8模块、2000台设备、200条网络参数、2000条连接，总CSV文本最多2MiB。不直接读取XLSX。重复资产编号、SN或同模块重复批次会阻止导入；这是新增/追加入口，重传文件不会更新已有设备。预览后数据发生变化需重新预览。示例文件见examples目录。

## 3. 导航与图形操作

空间路径：项目 → 空间总览 → 机房 → 微模块 → 机柜 → 设备。拓扑路径：项目 → 网络拓扑 → 机房；网络的包含路径在当前操作区显示，选择网络不隐藏其他网络。顶部路径逐层返回；侧栏选择工作区。

在拓扑点击“项目拓扑”或再次点击侧栏“网络拓扑”，返回当前项目总图并清除筛选。编辑页“返回查看”返回原位置；从拓扑定位机房后可“返回原网络拓扑”。刷新和浏览器前进/后退保留地址中的层级。保存时不能切换页面。

机房图的“＋／－”独立缩放，“适应画布”完整适配宽高。拓扑默认100%实际比例，底部“总览”缩放查看全图，点击百分比恢复100%；Ctrl／⌘＋滚轮按指针位置缩放，拖动画布空白处平移。右上角“界面显示”可收起导航、统计、网络列表、工具、图例及详情；“专注画布”一键收起并可恢复。偏好在当前浏览器保存。

详情“×”只收起，保留选择；“显示详情”或再次点击对象可以恢复。“取消选择”单独清除选择。拖动移动位置，详细参数进入编辑页；Esc取消未完成的拖动。

## 4. 机房、微模块和机柜

机房提供铺满画布的平面/立体示意，网格覆盖整个可用区域；拖动空白处平移，模块可直接拖动；选中后“旋转90°”或R切换方向。拖动按连续位置保存，不提供松手吸附。重叠或画布外释放会取消。位置图是示意，不代表工程尺寸。鼠标放在图上直接滚轮缩放，以鼠标所在位置为中心；缩放不修改模块位置。机房入口只需在图上方选择“上边/右边/下边/左边”，立即显示并自动保存；直接拖动入口可沿机房边界调整位置，松开自动保存，聚焦入口后可用方向键微调。选择“未设置”清除入口。失败时保留预览并显示重试/恢复入口，实际位置以现场为准。

进入模块后，机柜和独立设施按混排序列显示。拖动机柜可插入供电、空调等设施前后；其他对象只顺延让位，相对顺序保持。柜内集成设施跟随机柜，设备和连接不变。双排允许跨列；Alt+方向键微调，边缘自动滚动。

**增删入口：模块页 → 编辑微模块 → 机柜管理。**

- 选择L/R列，填写名称或留空自动编号，点击“新增机柜”；建成后仍可扩容。
- 删除机柜统一在确认窗口处理：默认把柜内设备移到本机房共享待上架区，保留资产、网络和连接。柜内设施标记单独列出，可在同一窗口勾选一并删除，不必逐项清理。也可明确选择连同设备删除，勾选确认后才删除设备及关联连接。
- 单排最多24柜，双排每列最多12柜。双排某列删空后自动转单排，另一列与独立设施保留；删除模块最后一个机柜时，直接打开整模块确认窗口，无需新建机柜绕过限制。
- “删除微模块”位于编辑页顶部、模块更多操作和机房图所选模块的位置操作中。窗口列出机柜、设施标记、在架及待上架设备。可一次将全部设备迁到同项目另一模块的待上架区后删除，或明确选择连同内容删除；后者清理设备、关联链路和网络成员引用，其他资产和网络分区保留。
- 柜名：选择机柜 → 编辑机柜详情。设施增删、名称和独立/集成方式在编辑微模块中配置。集成标记本身不扣U位，实际占U设备需入台账。

柜内设备在“柜内设备”视图拖到目标柜/U位，冲突不会保存。长柜列可筛选L/R、使用柜导航、调整大小或“两柜并排”。同机房跨模块上架可直接使用右侧共享待上架区，或在快捷机位表单中选择模块与机柜。

## 5. 布局模板

模块页“模块更多操作 → 存为布局模板”，填写模板名称后保存。侧栏布局模板可编辑、复制、删除、导入导出和复用。

模板包含型号、单双排、柜数、柜名、机柜/设施混排顺序和集成方式；不包含资产、IP/SN、网络、连接或机房图坐标。编辑模板不改变既有模块。模板JSON与规划JSON各有导入入口。

预设C2000单排5柜、双排左4右4、C500单排4柜均为项目示意。实际柜数、可用U位、供电制冷位置按现场配置确认；微模块型号不是普通服务器型号。

## 6. 网络、排列与连接

详见[网络拓扑使用说明](网络拓扑使用说明.md)。选择机房后全部相关网络在一张图里，内部网络真正嵌在父框内。点击网络只确定操作对象，父级、兄弟网络和跨网络连接始终保留。

- 统一“新建网络”，填名称、所属机房和放置位置，先看虚线预览再创建；可选用途、VLAN、网段按需填写。空网络有直接添加设备入口。
- 改名和调整上级在网络详情预览后应用。拖动标题只调图位置，父框与全部内部网络和设备一起移动，不改变包含关系或物理机位。
- 添加设备支持批量、筛选和拖入；设备详情每个所属网络旁可直接移出并撤销。未分配设备默认可见。
- 网络详情中的“显示层名称与分隔线”即时切换，不需要保存；“设置排列层”单独打开名称、数量、顺序及设备分配设置，修改后保存。空白区域不弹设置窗口。新网络默认隐藏分层标识。
- Ctrl/⌘选择两台设备可直接连接，也可打开两端独立搜索的链路表单。确认、编辑和删除直接可用，关系标签始终在线上。
- 删除网络只移除该网络和失效标签，直属内部网络提升一层，资产、真实连接和其他归属保留。
- 开关详情不重排设备或改变缩放。普通滚轮平移，Ctrl/⌘+滚轮锚定缩放，总览适应完整图；底栏独立占位。


## 7. 图片和PDF导出

机房位置图、微模块布局、机柜立面和拓扑旁“导出图形”支持PNG、单页PDF、SVG，包含屏幕外完整画布及标题/范围/时间，不包含导航与工具。

拓扑按当前筛选及展开状态导出；完整项目图先返回项目拓扑。立面拼接当前显示机柜，全部柜需退出两柜并排并选择全部列。PDF采用高清图像保留中文外观，文字不可检索；超大图会限制分辨率，放大查看建议SVG。导出在浏览器生成，不需要外网。

## 8. 审计与故障提示

记录资产增删/导入、机位、IP/SN、网络成员/层级/连接及关键配置；不记录纯图位置、旋转、配色和无变化保存。每条只保存变化对象的前后明细，界面显示最近200条，重要历史不按时间自动删除。

“精简历史记录”删除已有纯视觉/无变化记录，压缩完整快照为变化对象，保留重要编号、时间、摘要和业务值；未知格式原样保留。整理会回收加密文件空间，不改当前业务状态。失败会回滚。审计JSON用于追溯，不是完整备份。

遇到修订冲突，刷新后核实数据再操作；保存失败检查空间和目录权限。导入失败先按行号修正CSV。删除错误显示在确认窗口的按钮旁，保存时显示处理状态。修订冲突会刷新窗口数量并清除删除确认，核对后重新确认。

拓扑遇到历史位置重叠时会自动避让显示；拖动网络到其他分区上方会取消并提示。使用“画布操作 → 自动排列”由ELK辅助确定同层排序，按现有显示层排布并保存分区/设备位置；连接线沿正交通道绕过卡片，普通标签按需显示。一次最多1000台设备，较大范围先筛选网络。

删除窗口里的供电、空调、环境等“设施标记”与设备台账分别统计，可能由模板预置，不代表已经核实的实物设备。删除机柜或模块是删除管理系统记录，不执行实际设备操作。全部删除/迁移在一个事务中完成，写入失败不保留部分结果，并保留重要审计明细。


## 常用操作与快捷键

- 同一机房只有一份共享待上架列表，包含各微模块下尚无机位的设备；切换微模块或机柜后列表保持相同，其他机房和其他项目的设备不会混入。原有资产直接出现在共享列表中，无需重复导入。
- 进入“柜内设备”，先选择当前机柜，再点击设备行右侧“上架”，系统自动使用该柜从低到高的首段连续空闲U位。保存后设备从共享列表消失，保持列表打开，可继续安排下一台。也可把设备拖到任意可见机柜的指定U位。上架到其他微模块时同步更新设备所在模块，保留原设备ID、资产资料、网络和连接；下架后再次回到同机房共享列表。
- 共享列表支持按设备名、资产编号和型号搜索。型号高度未知或当前柜没有连续空位时禁用快捷上架并显示原因；换柜即可继续，冲突不会保存。维护中的设备上架后继续保留维护状态。
- 机柜立面选中设备后，右侧直接显示“移至待上架区”和“调整机位”。待上架设备可在当前页选择同机房任意模块的机柜和连续空闲U位，默认使用当前选中机柜，再确认上架，无需打开设备详情。机位变更后可立即撤销并恢复原机位与资产状态；后续有其他数据变更时撤销入口失效，避免覆盖新数据。
- 设备台账每行直接提供上架/下架入口与资产状态选择；IP、SN等详细资料仍进入编辑页。型号U高为0时先在型号库确认高度，不能上架。
- 拓扑画布顶部直接提供新增网络、链路与设备；选中设备后在“所属网络”每行点击“移出”，只解除该网络归属并可撤销。设备、其他归属和实际连接保留；移除全部归属后显示在未分配区。选中链路后可直接确认或改回待确认，链路新增/编辑使用窗口，先选两端设备，网络、速率与备注按需展开；删除也在详情直接可用。
- 总览“手动创建机房”、机房“新增微模块”、模块“新增设备”直接可见。少量机房的总览卡片与容器按内容限宽，已上架和待上架数量并列显示。
- 右上角“键盘快捷键”按钮或 `?` 查看说明。输入框、文本框和下拉菜单中不触发新增/导入等动作键，保存和Esc仍可用，修改密码页停用工作区快捷键；忙碌期间不能重复提交。

| 快捷键 | 操作 |
| --- | --- |
| `/` | 聚焦当前页面搜索 |
| `Alt+N` | 按页面新增设备、型号、模板、空间或网络 |
| `Alt+I` | 按页面导入设备、型号、模板，或导入初始化 |
| `Alt+E` | 编辑选中对象详细信息 |
| `Alt+L` | 拓扑新增链路 |
| `Alt+0` | 适应当前画布 / 机柜紧凑总览 |
| `Alt+U` | 选中设备移至待上架区 |
| `Ctrl+S` / `⌘+S` | 保存当前编辑表单，仍执行校验；多表单页先聚焦需要保存的表单 |
| `Esc` | 关闭弹窗或退出编辑，未保存时先确认 |
| `?` | 快捷键说明 |

## 型号库批量导入与设备角色

型号库为全局共享，顶部提供“导入型号”“导出型号”“管理角色”和“新增型号”。CSV UTF-8支持中文或英文字段：

| 字段 | 说明 |
| --- | --- |
| 型号 / model | 必填，型号名称唯一 |
| 设备角色 / role | 必填，填写已有角色名称或标识；可先自定义角色 |
| 厂商 / vendor | 可选 |
| U高 / u_height | 0–42整数，空或0表示待确认 |
| 端口说明 / ports | 可选，仅作台账说明 |

使用页面下载的模板，或 `examples/型号库-空白模板.csv`。选择CSV或粘贴内容后先预览，确认后才入库。单次不超过2MiB/2000个型号；相同定义自动跳过，同名参数冲突时整批拒绝，不覆盖已有型号。导入期间其他操作修改数据后，需要重新进入导入并预览。

“管理角色”支持新增角色、修改名称/颜色，引用型号自动使用新显示名称。自定义角色可选择拓扑分类，用于自动分层和连接推演；现有设备型号、设备编号及实际连接保留。内置分类不变；有型号引用的自定义角色不能移除。编辑型号时也可在“设备角色”选择“自定义新角色”，与型号一并保存。角色定义随数据库和加密数据一起持久化，不依赖浏览器本地设置。
